Agent System Map

Hệ thống agent hiện có, vẽ lại cho dễ hiểu

Trang này mô tả bản khung agent chúng ta vừa dựng: nó đã có lớp gọi model, harness, console, tool mẫu, cấu hình môi trường, và test cơ bản. Nó chưa phải một agent cá nhân hoàn chỉnh, vì còn thiếu mục tiêu riêng, dữ liệu riêng, tool thật, bộ nhớ dài hạn, cơ chế an toàn, và giao diện dùng hàng ngày.

Luồng chính hiện tại

người dùng → CLI → harness → model

Luồng này là xương sống của hệ thống. Người dùng gõ lệnh vào console, CLI đọc cấu hình, tạo Foundry chat client, bọc nó vào harness agent, rồi agent gọi model và tool khi cần.

Người dùng Nhập câu hỏi, yêu cầu tra cứu, hoặc lệnh hệ thống.
→
CLI + config Đọc biến môi trường, kiểm tra endpoint và chọn chế độ chạy.
→
Harness agent Gắn instruction, tool, memory, planning, todo, và web search.
→
Model + tools Gọi model, tool mẫu, và nguồn web khi bài toán cần dữ liệu ngoài.

trạng thái hiện tại
✓

✓

✓

✓

Có lệnh để xem mode, todo, xuất/nhập session.

1. CLI

Nhận lệnh, kiểm tra env, gọi console. Đây là cửa vào của hệ thống.

2. Harness

Bọc model bằng vòng lặp agent, gắn công cụ, memory, planning, todo.

3. Tools

Hàm mà model có thể gọi để lấy dữ liệu thật, không đoán bằng trí nhớ.

4. Memory

Nơi lưu sở thích, ngữ cảnh dài hạn, và các ghi chú bền vững giữa các phiên.

5. Planning

Chuyển yêu cầu mơ hồ thành kế hoạch, rồi mới thực thi từng bước.

6. GitHub Pages

Xuất trang mô tả hệ thống để xem online như tài liệu sống.

Những gì còn thiếu để thành agent cá nhân hoàn chỉnh

đây là phần quan trọng
!
Mục tiêu cá nhân rõ ràng

Agent phải biết nó phục vụ việc gì: học tập, công việc, tài chính, nghiên cứu, hay quản lý đời sống.

!
Tool thật

Kết nối Gmail, Calendar, Slack, Drive, Notion, database, file system, hoặc API riêng của bạn.

!
Memory dài hạn có cấu trúc

Không chỉ lưu session; cần quy tắc ghi nhớ, quên, và cập nhật những gì đúng là cần nhớ lâu.

!
Guardrails và phê duyệt

Hành động nguy hiểm phải có xác nhận, logging, và quyền hạn rõ ràng.

!
UI dùng hằng ngày

Có thể là web app, desktop, mobile, hoặc integration vào app bạn dùng thường xuyên.

!
Kiểm thử hành vi

Cần test cho prompt, tool call, memory, session restore, và lỗi ngoài đời thực.

Ví dụ ngắn

hệ thống hiện tại đang làm gì

Khi bạn nhập một yêu cầu, ví dụ "xem giờ hiện tại", agent sẽ đi qua khung này:

User input → CLI đọc FOUNDRY_PROJECT_ENDPOINT / FOUNDRY_MODEL → build_agent() → create_harness_agent(...) → model decide → tool get_current_time() → console in kết quả

Đó mới là "khung". Để thành agent cá nhân thật sự, cần đổi tool mẫu thành tool thật, thêm memory dài hạn, và gắn với công việc thực tế của bạn.

Trang này là bản mô tả trực quan của code hiện có trong workspace, không phải tài liệu chung chung.
