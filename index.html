Pham Vi V1

he thong nay dung de lam gi o thoi diem hien tai
Use case chinh

Personal Copilot ho tro mot Primary User doc hieu, sua, review, document, va research cong viec phan mem, dong thoi luu lai tri thuc tai su dung duoc trong repo nay.

Chi repo hien tai

V1 chua mo rong sang nhieu repo, cloud drive, inbox, hay he thong quan ly doi song. Tri thuc trong repo nay la local source of truth.

Work Surface

CLI la noi dien ra task intake, planning, verification, va completion report. Trang nay chi de quan sat va giai thich, khong phai giao dien thao tac chinh.

Quyet Dinh ADR

dien giai bang ngon ngu de doc
1
Search backend co the thay

Web research la bat buoc cho du lieu moi, nhung search backend khong bi khoa cung. V1 co the mac dinh dung Microsoft hosted search khi co san, trong khi hanh vi cua copilot van doc lap voi provider.

2
Bat dau voi mot repo

Multi-repo duoc hoan lai den sau khi core loop da on dinh. Cach nay giu cho repository edit, memory routing, va verification don gian hon trong V1.

Flow Van Hanh

mo ta nhanh kieu node flow de nhin nhu mot workflow engine
1. Task Intake

Ban nhap task tu do trong CLI. He thong dung intake.py de phan loai task thanh technical work, web research, memory work, local issue, secret config, hoac status page work.

→
2. Gate & Plan

autonomy.py va planning.py quyet dinh task co can nang autonomy, plan approval, hay lam ngay. Task lon, mo ho, rui ro se dung o buoc approve.

→
3. Execute

agent.py va harness goi model, tool, web research, backlog, hoac memory writer tuy theo task. Neu task la local issue hoac memory, co the xu ly ma khong can chat luan dai.

→
4. Verify

verification.py tim va chay check phu hop sau repository edit. Neu repo co pytest, script test, hoac package test command, ket qua se duoc dua vao report.

→
5. Report & Memory

reports.py tao Completion Report. memory_surface.py ghi learnings, errors, preferences da xac nhan, va feature requests vao .learnings/.

Node Input Output Module chinh
Task Intake Cau lenh tu do tu nguoi dung Task classification + route intake.py, console.py
Gate & Plan Task classification + autonomy hien tai Cho lam ngay hoac tao plan approval autonomy.py, planning.py
Execute Task da duoc route Agent response, memory write, local issue, hoac repo edit agent.py, backlog.py, memory_surface.py
Verify Task co thay doi repo Verification summary verification.py
Completion Ket qua task + verification + risk Completion Report hien thi trong CLI reports.py, console.py

Nhung Be Mat Da Co Trong Repo

dua tren code va tai lieu hien tai

Runtime va control surfaces

  • src/agent_harness/cli.py va console.py tao CLI work surface.
  • agent.py, instructions.py, va tools.py dinh nghia harness va tang tool.
  • config.py va __main__.py cung cap entry va wiring cau hinh.

Cac module capability da co spec ho tro

  • search.py dai dien cho abstraction search provider cua web research.
  • memory_surface.py dai dien cho memory surface backing bang repo.
  • backlog.py, autonomy.py, planning.py, reports.py, secrets.py, verification.py, va intake.py map truc tiep vao vocabulary cua V1.

Memory Surface

  • .learnings/LEARNINGS.md luu repo learning va working preference da duoc xac nhan.
  • .learnings/ERRORS.md luu loi lap lai, root cause, va verified fix.
  • .learnings/FEATURE_REQUESTS.md luu y tuong capability cho tuong lai.

Backlog

  • .codex/issues/ la backlog implementation-ready cho local issues.
  • Moi issue du cu the de mot agent hoac contributor khac co the nhat len va lam doc lap.
  • Backlog tach biet voi memory; no track buildable work thay vi durable knowledge.

Autonomy Levels

cac che do quyen han da duoc dinh nghia cho V1
E
Edit Mode

Che do mac dinh cua V1. Duoc sua repo va chay verification, nhung delivery action van can approval hoac mode cao hon.

D
Deliver Mode

Copilot duoc sua repo va thuc hien delivery action duoc yeu cau truc tiep nhu commit, push, tao PR, hoac buoc publish tuong tu.

A
Auto Mode

Copilot duoc tu chon repository edit va delivery action can thiet trong boundary ro rang do Primary User dat ra.
